# MCP From Zero

Code for the "MCP From Zero" video series: building a Model Context Protocol server for **TrailMart**, a small outdoor-gear shop's support desk, step by step.

- MCP specification: 2026-07-28
- Python SDK: `mcp` 2.3.0
- PostgreSQL 18

Each chapter's code lives in `chapters/NN-slug/`. The finished server grows in `trailmart/`.
